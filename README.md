# X12O

**Think big. Play smart.**

X12O is a strategy game built around a 12×12 board. The first milestone is a polished, offline-first Android game foundation with local two-player Classic matches. The architecture keeps the rules engine independent from the Flutter UI so AI, abilities, private rooms, and online matchmaking can be added without rewriting the core.

## Technology

- Flutter / Dart for the app and game UI
- Pure Dart rules engine
- Flutter Test for deterministic rules tests
- GitHub Actions for analysis and test automation
- Android application ID: `com.sbikazis.x12o` (generated by the bootstrap script)

No paid assets or third-party runtime packages are required for the current foundation.

## Classic rules (v1)

- Board: 12×12.
- Players alternate X and O, with X starting.
- A point is awarded for every new contiguous three-cell window completed horizontally, vertically, or diagonally.
- Longer runs count overlapping windows: four in a row = 2 points; five in a row = 3 points.
- Each three-cell window is awarded exactly once, when the final cell needed to complete it is placed.
- The match ends when all 144 cells are occupied. The higher score wins; equal scores are a draw.

## Run locally

Install Flutter stable and Android Studio / Android SDK, then:

```bash
git clone https://github.com/sbikazis/X12O.git
cd X12O
bash scripts/bootstrap_android.sh
flutter doctor
flutter run
```

The bootstrap script generates the standard Android project files if they are not present yet.

## Verify

```bash
flutter analyze
flutter test
```

## Roadmap

1. Offline Classic mode and tested rules engine.
2. Tactical Arena abilities and balanced energy economy.
3. Local AI opponents with difficulty levels.
4. Player profile, match history, achievements, and accessibility polish.
5. Private online rooms, invitations, matchmaking, and server-authoritative ranked play.
6. Carefully placed AdMob placements outside active matches.

Online multiplayer and ads are intentionally not represented as implemented in this initial foundation.
